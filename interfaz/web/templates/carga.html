🎲 Generar pedidos aleatorios

Crea pedidos con peso y direccion generados al azar. Sirve para probar el sistema y para ver como se comportan los algoritmos con volumen: la burbuja con 2000 pedidos tarda mucho mas que QuickSort.

Dos ejecuciones con la misma semilla generan los mismos pedidos. Dejala vacia para resultados distintos cada vez.
Los pesos usan una distribucion Pareto: muchos pedidos ligeros y unos pocos pesados, que es como se comporta una operacion de reparto real.
